# Master research · IAAC MaCAD 2022–23

Research notes by Alberto Carro Novo: SYneRgism, EASE and Latent Studio, each with a small 3D tool.
Static site, no build step: three.js r128 loads from cdnjs, its examples from jsDelivr, the font from Google Fonts.

Open `index.html` through a web server (GitHub Pages, or `python3 -m http.server` locally); opened as a
file, the browser blocks the data files the tools read.
